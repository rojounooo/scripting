## Bash 

### Ping 
- Sending ICMP packets to confirm a remote machine can be reached
- `-c` can be used to set the number of packets 

### DNS Lookup 
- Translates a Domain to an IP
- Use `nslookup` or `dig`

### Reverse DNS Lookup 
- Translates an IP to a DOmain 
- Use `nslookup`

### Traceroute 
- Shows path packets take 
- `traceroute` command
